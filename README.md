Requirements

* Java Development Kit (JDK)
* A terminal or command prompt

How to Run

Compile and run each Java program from the repository folder.

Example for Week 1:

javac week01/FirstProgram.java
java -cp week01 FirstProgram

Use the corresponding file path and class name for the other programs.

Learning Outcomes

These exercises practise Java syntax, output statements, user input, variables, arithmetic operations, and basic problem-solving.

The programs still need to be compiled and run to verify their outputs.
